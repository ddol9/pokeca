작가 화면

PR #9에서 추가했어요. 지금은 구글 로그인만 켜져 있고, 카카오는 비즈 앱 전환 뒤 켜요.

어드민 화면

창업자 한 명이 쓰는 운영 화면이에요. 표와 폼 위주로, 공개 화면과 같은 색을 써요.

데모 도안 그림은 자리 표시용으로 만든 그라데이션이에요. 실제 작가 도안이 아니에요.

노란 표시는 이번 PR #10에서 새로 생기거나 바뀐 화면이에요. 괄호 안의 2A, 5A 같은 번호는 설계 문서의 디자인 결정 번호예요.
